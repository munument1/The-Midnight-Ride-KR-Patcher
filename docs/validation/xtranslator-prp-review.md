1. 제작자 McGuffin의 [배포 페이지](https://www.nexusmods.com/starfield/mods/313)와 [1.7.3 변경 기록](https://www.nexusmods.com/starfield/mods/313?tab=logs): 현재 배포판은 2026-10-08 갱신된 1.7.3입니다. OFST/CLSZ 월드 인덱스를 저장할 때 임시로 제거하여 게임 충돌을 피한다고 명시합니다. 고급 데이터 분석 중 soft lock 수정은 별도 항목입니다.
2. 제작자가 연결한 [공식 GitHub 저장소](https://github.com/MGuffin/xTranslator): 조회 시 main의 HEAD는 `9aa38d60860273401f8bb0dd1557c82a295c41b3`(2024-10-02, 1.6.0)이며, 다른 브랜치나 태그는 없습니다.
3. 위 커밋의 [README 버전 기록](https://github.com/MGuffin/xTranslator/blob/9aa38d60860273401f8bb0dd1557c82a295c41b3/_ReadMe.txt#L106)과 [ESP 파서/저장 소스](https://github.com/MGuffin/xTranslator/blob/9aa38d60860273401f8bb0dd1557c82a295c41b3/TESVT_espDefinition.pas): 공개된 전체 소스에서 OFST/CLSZ 제거 구현을 찾을 수 없습니다. 이 소스는 1.7.3보다 오래됐습니다.

따라서 **1.7.3 구현을 소스로 직접 확인했다고 주장할 수 없습니다.** 확인 가능한 것은 제작자가 공개한 삭제 정책입니다. 최신 소스의 조건·예외·압축 처리와 우리 코드를 일대일로 비교한 상태도 아닙니다. PRP 파일명에만 적용되는 특별 분기인지도 변경 기록만으로 단정하지 않습니다.

## 판단

OFST/CLSZ 제거 자체를 근거 없는 삭제라고 설명한 것은 부정확했습니다. 최신 배포판 제작자가 명시한 충돌 회피 정책이므로 이를 유지합니다. 다만 제작자도 임시 대응으로 설명하며, 이것이 엔진의 모든 동작이나 성능에 대한 검증을 뜻하지는 않습니다. 검증되지 않은 오프셋 재계산 방식으로 바꾸지는 않습니다.

우리 구현은 `WRLD` 하위의 `OFST`와 `CLSZ`, 그 필드에 연결된 `XXXX`만 제거합니다. 다른 필드의 `XXXX`와 비표시 데이터를 보존합니다. 압축 WRLD를 처리하고 변경된 레코드·상위 GRUP 길이를 갱신합니다. 지원하지 않는 TES4 인덱스는 입력 단계에서 거부합니다. 번역할 내용이 없으면 플러그인 출력도 만들지 않습니다.

## v1.0.4에서 보강한 부분

기존의 개발용 사후 검사 외에 **최종 파일 전체 검증을 백엔드 실행 과정에 추가**했습니다.

- 텍스트 치환과 인덱스 제거가 모두 끝난 파일을 원본과 다시 비교합니다.
- 레코드/GRUP의 중첩·순서·식별자·헤더는 길이 값 이외에 같아야 합니다.
- 변경 가능한 표시 필드는 레코드 종류·필드 종류·원문·번역문까지 사전과 일치해야 합니다.
- 그 외 필드는 필드 헤더와 `XXXX`를 포함한 원시 바이트가 같아야 합니다.
- 지몬자 고정 ID는 원본 마스터 인덱스로 해석하며, 모드 소유 Zimonja EditorID도 검사합니다. 보호 레코드는 압축 바이트와 헤더까지 그대로여야 합니다.
- 제거한 OFST/CLSZ 개수와 최종 비교 결과가 일치해야 합니다. 출력에 인덱스가 남으면 검사가 실패합니다.
- 어느 저장/검증 단계에서든 실패하면 출력 플러그인을 삭제하고 실패를 보고합니다.
- 정책 6과 `final_binary_verified`, 명시적인 `world_index_policy`를 기록합니다. 정책 5 이하의 exact payload는 재사용하지 않고 새 백엔드로 생성합니다.

실제 PRP/PPF 표본과 압축·확장 크기·헤더 변조·비번역 필드 변조·필드 누락·인덱스 잔존·지몬자 변경을 검증합니다. 이 검증은 파일 손상 방지 범위를 넓히지만, 게임 내 지형·프리비즈·성능·CTD 비교를 대체하지 않습니다.

# v1.0.3 — TMR 2026-10-19 및 PR #1 통합

10월 19일판 TMR의 Simple FOV Slider가 영문으로 남고 Safe Travels의 새 옵션과 변경된 홀로테이프 메뉴 순서가 기존 사전과 맞지 않던 문제를 수정했습니다.

## 번역

- Extended 비공식 플러그인 60개: v1.0.2 대비 신규 5개, 변경 15개, 동일 40개.
- 신규: Hit Those Objects, Simple FOV Slider, Stiff Splines, 분리된 Terrain/Object LOD 플러그인.
- 신규 플러그인의 표시 문자열은 번역할 내용이 없거나 내부 프로그램 이름입니다. Simple FOV Slider의 실제 설정 화면은 Interface 사전으로 23문구를 번역합니다.
- Safe Travels Interface 신규 4문구를 보완했습니다. MCM 22 / Safe Travels 45 / Simple FOV Slider 23문구가 모두 매칭됩니다.
- Safe Travels 터미널의 ITXT·RNAM 배열 순서를 현재 버전에 맞춰 갱신했습니다. 터미널 55문구와 다른 표시 필드 9개를 번역합니다.
- 제거된 LegendariesTheyCanUse 및 구형 통합 LOD payload는 현재 exact 목록에서 제외합니다. 선택 모드를 위한 기존 사전은 유지합니다.

## PR #1

manbokgo의 [한국어 저장 및 Interface 인코딩 수정](https://github.com/munument1/The-Midnight-Ride-KR-Patcher/pull/1)을 현재 백엔드와 충돌 해결하여 통합했습니다.

- Interface TXT는 UTF-16 LE BOM으로 출력하고 `_en` 이름과 원본 줄바꿈을 보존합니다.
- 일반 문자열인 ScriptNotes 등은 대사와 원문이 같아도 치환하지 않습니다.
- exact payload는 정책 5, 원본 해시, UTF-8·재읽기 검증 정보, payload 해시와 WRLD 검사까지 통과해야 재사용합니다. 누락된 파일·검증 정보는 사전 경로로 전환합니다.
- 기여자의 인코딩 회귀 테스트와 패키지 자체 검사를 통합했습니다.
- v1.0.2의 OriginalTextWriter, 지몬자 제외, WRLD OFST·CLSZ 제거는 유지합니다. localized 문자열 테이블 재직렬화는 제외하고 명시적인 경고를 유지합니다.

## 검증과 한계

실제 설치본의 영문 원본을 읽어 payload를 다시 만들었습니다. 원본 설치 폴더·프로필·세이브는 변경하지 않습니다. 테스트와 파일 검증 결과는 게임 내 안정성 검증을 대체하지 않습니다. 기존 손상 파일은 영문 원본 복원이 필요합니다.

- 회귀 테스트 35개 통과, 스킵 없음. 현 설치본의 PRP 두 플러그인도 검사했습니다.
- Extended: 39개 플러그인의 표시 필드 24,137개를 치환했습니다. 독립 바이너리 대조에서 레코드·헤더·필드 순서와 비번역 데이터 보존을 확인했습니다.
- Base: 비공식 플러그인 18개 중 번역 payload 13개, 표시 필드 22,353개를 확인했습니다.
- 새 GUI EXE의 Tcl 초기화·Output 생성·payload 메타데이터·Interface UTF-16 LE 검사를 통과했습니다.
- Extended의 `Simple Everyone's Best Friend.esp`는 localized 플러그인이므로 제외 경고 1개가 예상됩니다. Base에는 경고가 없습니다.

## 개발용 재생성

공식 v1.0.2 ZIP을 풀어 이전 패키지의 본편 리소스와 사전을 준비합니다. 새 폴더 경로를 사용하세요.

```powershell
dotnet publish tools/TmrPluginTranslator -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o build/Backend
python tools/refresh_release.py --previous ReleaseBase/v1.0.2/TMR-Korean-Patcher-v1.0.2 --mo2-root C:/Modlists/TMR --package ReleasePackage-v1.0.3 --output Output-v1.0.3 --backend-exe build/Backend/TmrPluginTranslator.exe
python tools/verify_release_output.py Output-v1.0.3 --data ReleasePackage-v1.0.3/TranslationData --report reports/preservation-v1.0.3.json
python -m PyInstaller --noconfirm TMR-Korean-Patcher.spec
Copy-Item dist/TMR-Korean-Patcher.exe ReleasePackage-v1.0.3/TMR-Korean-Patcher.exe
```

`refresh_release.py`는 소스 관리되는 `TranslationData/updates`의 신규 사전을 반영합니다. 패키지에는 최신 README·릴리즈 노트도 복사해야 합니다. 완성된 실행 파일은 패키지 폴더에서 `--self-test C:/Modlists/TMR`로 검사합니다.

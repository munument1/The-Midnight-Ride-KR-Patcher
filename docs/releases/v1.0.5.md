# v1.0.5 — 완성 플러그인 배포 제거

배포 패키지에 포함했던 완성된 플러그인을 제거했습니다. ZIP에는 실행 도구, 번역 사전과 본편 한국어 리소스만 포함하며 ESP/ESM/ESL 파일은 포함하지 않습니다.

## 현재 설치본에 적용

기존 버전도 원본 SHA-256이 일치할 때만 완성 플러그인을 복사하고, 다르면 사전 번역으로 전환했습니다. v1.0.5에서는 그 복사 경로 자체를 삭제했습니다. 이전 카탈로그의 payload 항목이 남아 있어도 사용하지 않습니다.

모든 대상은 현재 설치된 플러그인에서 읽고, 레코드와 표시 원문이 일치하는 번역을 적용합니다. 업데이트로 추가된 레코드·헤더·비번역 데이터는 현재 파일을 기준으로 보존합니다. 바뀐 원문은 과거 번역으로 대체하지 않으며 미대응 문구로 남을 수 있습니다. 번역 사전은 모드 변경에 맞춘 추가 검수가 필요합니다.

최종 바이너리 검증, UTF-8 재읽기, 지몬자 번역 제외, WRLD OFST/CLSZ 처리 정책은 유지합니다. 입력 파일이 처리 도중 바뀌면 생성을 중단합니다. 빠른 완성 파일 복사 대신 직접 번역하므로 생성 시간이 늘어날 수 있습니다.

## 배포 검증

- 실제 백엔드를 사용하여 원본 해시 일치, 업데이트된 헤더와 추가 레코드 보존, 원문 변경 시 구번역 미적용을 검사합니다.
- 사용자 설치본과 별도로 구성한 원본 모드 검증 환경에서 Output을 생성하고 원본과 비교합니다. 실제 게임 설치 파일은 수정하지 않습니다.

- 자동 검사 42개 통과(제거한 별도 ZIP 검사 테스트는 제외), 스킵 없음.
- 실제 모드 39개를 설치 원본에서 생성하고 표시 필드 24,137곳에 번역을 적용했습니다.

## 설치와 제한

ZIP 전체를 풀고 TMR MO2 폴더를 선택해 Output을 생성한 뒤, Output 안의 mods 및 필요한 경우 overwrite를 MO2 루트에 복사합니다. FO4 KOREAN을 사용할 프로필에서 활성화하세요.

TMR 업데이트 후에는 최신 설치 파일을 기준으로 Output을 다시 생성해야 합니다. 과거 Output을 새 모드에 덮어쓰지 마세요. 이미 문자열 자체가 손상된 파일은 공식 원본으로 복원한 뒤 적용하세요.

현 내장 폰트의 일부 음절 누락과 localized 플러그인 제외는 유지합니다. v1.0.4 사용자 플레이 결과를 새 버전의 인게임 검증으로 간주하지 않습니다. v1.0.5는 별도 인게임 확인이 필요합니다.

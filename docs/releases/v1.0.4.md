# v1.0.4 — 최종 플러그인 원본 대조 검증

xTranslator 1.7.3 제작자의 변경 기록에서 OFST/CLSZ를 임시로 제거하는 저장 정책을 확인했습니다. 공식 GitHub 소스는 1.6.0에 머물러 있어 1.7.3 구현을 소스로 직접 비교한 것으로 설명하지 않습니다. [출처와 판단 근거](../validation/xtranslator-prp-review.md)를 확인하세요.

삭제 정책과 번역 내용은 유지하고, 저장한 최종 플러그인 전체를 원본과 대조하는 검증을 런타임에 추가했습니다. 사전과 일치하는 표시 문자열·WRLD의 지정 인덱스 제거·필요한 길이 갱신 외의 변경은 거부합니다. 지몬자 보호 레코드는 전체 바이트를 보존해야 합니다. 실패 시 출력 파일을 폐기합니다.

정책 버전 6으로 exact payload를 다시 만들었습니다. 이전 정책의 payload 또는 최종 바이너리 검증 정보가 없는 payload는 빠른 적용에 사용하지 않습니다. 설치 방식은 동일하며 기존 설치본·프로필·세이브는 Output 생성 과정에서 변경하지 않습니다.

검증 결과:

- 회귀 테스트 42개 통과, 스킵 없음. 비번역 데이터/헤더 변조, 필드 누락, 인덱스 잔존, 지몬자 변경을 거부하는 검사를 포함합니다.
- Extended 39개 payload / 표시 필드 24,137개, Base 13개 payload / 표시 필드 22,353개를 독립 바이너리 검사로 확인했습니다.
- 새 백엔드로 재생성한 플러그인 39개의 SHA-256은 v1.0.3의 대응 파일과 모두 같습니다. 삭제 정책을 바꿀 파일 차이는 발견하지 않았으며, 이번 수정은 최종 보존 조건의 런타임 강제입니다.
- 새 GUI 실행 파일의 패키지 자체 검사를 통과했습니다. Extended의 localized 플러그인 제외 경고 1개는 기존과 같고, Base에는 경고가 없습니다.

파일 검증과 게임 내 검증은 별개입니다. 실제 지몬자 접근·셀 전환·지형·프리비즈·성능 비교는 아직 수행하지 않았습니다.
